# ALX Listing App

The ALX Listing App is a modern Airbnb-style listing page built using **Next.js**, **TypeScript**, **TailwindCSS**, and **ESLint**.

##  Project Goals

This project scaffolds the foundation for a property listing page with:

- Scalable, maintainable structure
- Type-safe reusable components
- Clean styling with TailwindCSS

##  Project Structure

- `components/` – Reusable UI components (`Card`, `Button`)
- `interfaces/` – TypeScript interfaces for props and models
- `constants/` – Reusable constants like API URLs or default images
- `public/assets/` – Images, SVGs, and other static assets
